# Instrucciones aportadas para el caso de Compiladores

- Trabajar en los grupos conformados al inicio del semestre.
- El lenguaje de entrada es Compiscript.
- Herramientas generadoras de analizadores, lenguaje de implementación y librerías a elección.
- Es obligatorio usar una herramienta generadora de analizadores léxicos y sintácticos; una implementación completamente manual se penaliza con cero puntos.
- Interfaz gráfica amigable y estética; incumplir resta cinco puntos.
- Seleccionar el archivo de entrada desde la interfaz; incumplir resta cinco puntos.
- Mostrar resultados de análisis y representación intermedia dentro de la interfaz, no solo consola; incumplir resta cinco puntos.
- Cada grupo escribe los archivos de prueba usados en la calificación.
- No detener el análisis al primer error: intentar reportar múltiples errores con recuperación efectiva; incumplir resta cinco puntos.
- Evitar errores repetidos, ciclos infinitos durante recuperación y mensajes derivados sin utilidad; incumplir resta cinco puntos.
- No generar representación intermedia si hay cualquier error léxico, sintáctico o semántico.
- El alcance se limita a análisis léxico, sintáctico y semántico y representación intermedia; no ejecutar el programa ni producir código objeto. Incumplir esta restricción se penaliza con cero puntos.
